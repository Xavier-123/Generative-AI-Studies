# 简介

## 项目名称：
金融级大模型高可靠抗幻觉推理系统（Agentic RAG）
## 技术栈：
PyTorch、Qwen3.5、Agentic RAG、FAISS/Milvus、vLLM、RAGAS、LoRA/SFT
## 项目概述：
针对金融复杂问答、信贷合规与智能风控场景中大模型的事实幻觉与逻辑推理幻觉问题，主导研发基于 Qwen3.5 基座 的分层检索增强、多阶段推理验证与自我反思（Self-Correction）高可靠推理框架，提升复杂多跳业务场景下的推理忠实度与可解释性。
## 核心职责：
1.可信推理流水线： 
	设计“意图解析→多粒度检索→链式推理→事实验证→动态反思”五阶段架构，引入任务分解与分步推理，支持复杂金融决策场景。
2.Agentic RAG 检索：
	# 可以先简单说一下 “Token级 - 句子级 - 段落级 - 文档级” 这块设计
	落地 Small-to-Big 多粒度架构，打通 “Dense + BM25 混合召回 ➔ 滑动窗口语境扩展 ➔ Cross-Encoder 精排”流水线；结合 ReAct 动态路由与 HyDE 改写，规避长文本截断与“迷失（Lost-in-the-Middle）”，实现金融多跳（Multi-hop）证据的精准自主召回。
3.抗幻觉与自纠错： 
	融合 Chain-of-Verification（CoV）、Self-Consistency、Reflexion，构建“幻觉检测→证据补全→自我修正”闭环，提升回答事实性与推理可靠性。
4.领域模型微调：
	构建金融 CoT、批判与反思数据集，采用 SFT/LoRA 对 Qwen3.5 进行领域对齐，增强模型证据遵循、冲突识别与反思能力。
5.评测与工程优化： 
	基于 vLLM 优化推理部署，端到端 TTFT 降低 30%+；搭建 RAGAS + 自建金融基准评测体系，业务忠实度与准确率提升 25%+。


# 详细描述
## 项目名称：
金融级大模型高可靠抗幻觉推理系统（Agentic RAG）
## 技术栈：
Python、PyTorch、Qwen3.5(MoE/Dense)、Agentic RAG、FAISS/Milvus、vLLM、RAGAS、LoRA/SFT
## 项目概述：
针对金融复杂问答、信贷合规与智能风控场景中大模型的事实幻觉与逻辑推理幻觉问题，主导研发基于 Qwen3.5 基座 的分层检索增强、多阶段推理验证与自我反思（Self-Correction）高可靠推理框架，提升复杂多跳业务场景下的推理忠实度与可解释性。
## 核心职责：
1.搭建多阶段可信推理流水线：
	设计“意图解析-多粒度检索-链式推理-事实验证-动态反思”五阶段协同架构，针对金融长文档与数值计算引入分步分解机制，支持复杂决策逻辑的闭环推导。
2.构建 Agentic RAG 检索引擎：
	设计基于 Small-to-Big（父子文档） 机制的多粒度索引架构，采用“Dense + Sparse 并发召回子切片 ➔ 动态滑动窗口扩展至父级语境 ➔ Cross-Encoder 语义精排”流水线；结合 ReAct 动态路由、Query 改写与 HyDE，有效避免“迷失在中间（Lost-in-the-Middle）”与语义截断，实现金融长文档多跳（Multi-hop）证据的自主探索与高精度召回。
3.实现验证链（CoV）与自纠错闭环：
	融合 Chain-of-Verification、多路径一致性采样（Self-Consistency）与反思智能体（Reflexion），构建“幻觉检测 → 靶向证据补全 → 自我修正”机制，将生成内容的事实性错误率大幅降低。
4.领域基座模型微调（SFT/LoRA）：
	针对推理与反思阶段，构建数千条金融高质量 CoT 推理与批判数据集，对 Qwen 基座进行指令微调与领域对齐，显著增强了模型遵循证据链与自主发现矛盾的能力。
5.工程落地与自动化评测体系：
	基于 RAGAS 与自建金融事实基准（Financial Benchmark）搭建自动化评测流水线；后端接入 vLLM 实现 PagedAttention 推理加速与动态批处理，系统端到端首字延迟（TTFT）降低 [30%+]，忠实度（Faithfulness）与回答准确率提升 [25%+]。
