# 简历版本
## 项目名称：
大模型训推与异构算力适配平台
## 技术栈： 
Python、CUDA、CANN、MindIE、vLLM、SGLang、FastAPI、Docker、LoRA/QLoRA、模型蒸馏、LLM
## 项目描述：
	搭建覆盖“数据-训练-蒸馏-推理-管理”全流程的一站式训推平台，屏蔽GPU、昇腾910B、DCU等异构算力差异，统一纳管LLM、多模态、Embedding及Reranker模型。累计完成10+模型跨平台适配落地，将模型交付周期由3天缩短至1天内，部署缩短至30分钟，整体提效60%以上。
## 核心工作：
1.数据工程与CoT蒸馏：
	构建“生成-清洗-质检-回流”闭环流水线，基于教师模型实现CoT级知识蒸馏与多维质检（PPL/去重），减少50%+人工标注依赖。
2.多范式训练平台研发：
	统一封装PT/SFT/DPO/PPO/GRPO等范式，支持Full/LoRA/QLoRA策略自适应选择，实现流水线编排、断点续训及全指标监控。
3.异构算力与国产化适配：
	基于MindIE与MindFormers攻克昇腾910B环境下的权重转换与兼容性难题，完成百川、浪潮等模型迁移适配及多机多卡分布式性能调优。
4.高性能推理优化：
	集成调度vLLM、SGLang、MindIE等引擎，针对KV Cache与Continuous Batching进行深度优化，显著降低首字延迟并大幅提升吞吐。
5.模型资产与标准化交付：
	搭建统一Model Registry纳管全品类模型，通过FastAPI与Docker打通容器化部署链路，实现模型一键交付上线。
	

# 详细描述版本
## 项目名称：
大模型训推与异构算力适配平台
## 技术栈：
Python、CUDA、CANN、MindIE、vLLM、SGLang、FastAPI、Docker、LLMs、LoRA/QLoRA、模型蒸馏、Embedding、Reranker、多模态模型
## 项目描述:
	搭建面向企业级AI应用的一站式大模型训推与异构算力适配平台，覆盖数据处理、模型训练、模型蒸馏、推理部署、模型管理及跨硬件适配全生命周期能力。平台底层对接Kubernetes实现任务调度与资源编排，上层屏蔽GPU / NPU（昇腾910B）/ DCU等异构算力差异，统一提供模型训练与推理API能力。支持LLM、多模态模型、Embedding、Reranker及语音模型统一纳管，累计完成10+模型跨平台迁移与生产部署，将模型交付周期由3天缩短至1天以内，推理部署从1天缩短至30分钟，整体研发与运维效率提升60%以上。
## 核心工作:
1. 数据工程与模型蒸馏体系建设
    构建“数据生成 → 清洗 → 质量评估 → 回流优化”的闭环数据流水线，实现训练数据自动化生产
    基于教师模型（LLM）构建CoT级知识蒸馏机制，自动生成高质量问答对与推理链数据
    设计多维数据质量评估指标（语义重复度、困惑度、任务一致性），提升数据有效性
    将低质量人工标注依赖降低 50%+
2. 多范式训练平台研发
    统一抽象 PT / SFT / DPO / PPO / GRPO 多类训练范式，构建可插拔训练执行框架
    支持 Full Fine-tuning / LoRA / QLoRA 自动策略选择（基于显存与任务类型）
    设计训练任务编排系统（Pipeline化），支持断点恢复、失败重试与任务优先级调度
    实现训练过程指标可观测（loss / grad norm / lr / GPU util）
3. 异构算力适配与国产化迁移
    在昇腾910B环境下完成浪潮、百川等大模型的推理与微调迁移
    基于MindIE/MindFormers解决模型加载、权重转换及训练推理兼容问题，支持LoRA/SFT等训练验证
    完成单机多卡与多机多卡性能测试与瓶颈分析
4. 高性能推理与服务部署优化
    集成vLLM、SGLang、MindIE等主流推理引擎，实现不同硬件环境下推理框架统一调度；
    优化 KV Cache / batch 合并 / continuous batching 提升吞吐能力
5. 模型资产管理与平台化建设
    构建统一 Model Registry（LLM / Embedding / Reranker / 多模态）
    提供 FastAPI 标准化服务接口 + Docker 化部署链路
## 项目成果
    支撑GPU、NPU、DCU三类异构算力环境统一管理；
    完成10+模型跨平台适配与生产部署；
    模型交付周期由3天缩短至1天以内；
    模型部署周期由1天缩短至30分钟；
    运维成本降低50%，整体研发与交付效率提升60%以上；
    支撑多个企业级AI应用场景快速落地与迭代。
